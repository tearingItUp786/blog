# TanStack Hotkeys Implementation Plan

**Goal:** Replace the existing hotkey implementation without adding navigation
or scrolling commands.

**Architecture:** A typed app registry and root provider own bindings and local
preferences. Exclusive overlay scopes arbitrate Escape; one search registration
moves between global and search scopes. A footer-accessible shortcut sheet
records only the search binding.

**Tech Stack:** React, TypeScript, TanStack React Hotkeys 0.17.0, Vitest/jsdom,
pnpm.

**Spec:** User-approved design in this conversation: Mod+K search, fixed Escape
dismissal, lazy Algolia loading, platform labels, held-modifier hints, persisted
rebinding with conflict rejection. Logical keys are appropriate; no default
sequences or physical-position bindings are needed.

## Constraints

- Preserve mobile menu and article TOC focus behavior.
- Preserve light/dark themes, CommitMono and the pink accent.
- Persist only validated search overrides; tolerate unavailable storage.
- Avoid changing unrelated user work or creating new keyboard commands.
